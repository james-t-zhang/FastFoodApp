# FastFoodApp

A McDonald's-inspired fast food ordering app built with Python and Kivy, 
designed to run on Windows, iOS, and Android.

## Overview

FastFoodApp is a cross-platform mobile/desktop application that simulates 
a fast food ordering experience. Users can browse a menu, build and customize 
a cart, and apply rewards — all through a Kivy-based GUI.

## Technologies Used

- Python
- Kivy (cross-platform UI framework)
- Map API (in progress)

## Features

- Browse menu and add items to cart
- Customize and remove items from cart
- Apply rewards with condition checking
- Settings panel with login section (in progress)
- Location selector with map UI (in progress)

## Setup & Installation

1. Clone the repository
2. Install dependencies:
   pip install kivy
3. Run the app:
   python main.py
